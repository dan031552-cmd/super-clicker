# אשכנזי — חנות חולצות

חבילת אתר סטטית מוכנה להעלאה ל-GitHub Pages, Netlify או Vercel. האתר נבנה ללא תמונות בשלב הזה; אזורי הגלריה כבר קיימים ומוכנים להחלפה בתמונות אמיתיות.

## מבנה הקבצים

- `index.html` — מבנה החנות, הקטלוג, הגלריה, הביקורות, הסל והחלונות הקופצים.
- `styles.css` — העיצוב הרספונסיבי, כולל מצב הזהב של הקופון.
- `script.js` — קטלוג, תמחור, סל, הזמנה בוואטסאפ, קופון, ביקורות ו-`localStorage`.
- `admin/README.md` — הכנה לחיבור עתידי למערכת ניהול.

## לפני פרסום

1. מספר הוואטסאפ כבר מוגדר ל-`972552956401`, בהתאם למספר שסיפקת. אם המספר ישתנה בעתיד, מעדכנים את `WHATSAPP_NUMBER` בראש `script.js` בפורמט בינלאומי, בלי `+`, רווחים או מקפים.
2. מחליפים את שלושת אזורי הגלריה ב-`index.html` בתמונות כאשר הן יהיו מוכנות. אין צורך לשנות את הלוגיקה.
3. מעלים את כל התיקייה כפי שהיא ל-GitHub.

## כללי המחיר שהוגדרו

- חולצה רגילה: 70 ש״ח, עם מחיר קודם 80 ש״ח בקו חוצה.
- הדפסה על הגב: 90 ש״ח, עם מחיר קודם 100 ש״ח בקו חוצה.
- שלוש חולצות ומעלה: 60 ש״ח לחולצה. המבצע חל גם על חולצות עם הדפסה בגב, לפי ההגדרה הנוכחית: 60 ש״ח ליחידה לאחר המבצע.
- קוד סודי `2323`: מוריד 10 ש״ח, אך אינו פעיל כאשר יש 3 חולצות ומעלה. בהפעלה האתר עובר למצב זהב, רועד קלות ומציג קונפטי.
- משלוח: תוספת 5 ש״ח. איסוף עצמי: ללא תוספת.
- מידות: `XS, S, M, L, XL, XXXL` וכל המידות המספריות `1–47`. המידה `XXL` לא מוצגת לבקשתך.

## בדיקה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. אם הדפדפן חוסם התנהגות מסוימת של קבצים מקומיים, להריץ שרת סטטי פשוט מתוך התיקייה, למשל עם VS Code Live Server.

## הערת פרטיות

בגרסה הנוכחית הסל והביקורות נשמרים בדפדפן של המשתמש באמצעות `localStorage`. זו הכנה נוחה לגרסה ראשונה, אך מערכת ניהול אמיתית תדרוש שרת ומסד נתונים.
